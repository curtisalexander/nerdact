Methods, checkpoint records, and test machine

All rows use a confidence threshold of 0.5. Revisions appear in the table and the machine-readable artifact.

Timing

Each checkpoint ran in a fresh process. After one untimed warm-up example, NERdact timed sequential, single-example inference over the 3 domain transcripts for 3 repeats using a monotonic clock and device synchronization. Throughput is examples per second. Memory is peak reserved accelerator memory on CUDA, complete-process peak RSS on CPU, and the maximum post-inference sample of current driver allocation on MPS; transient MPS allocations may be missed. Cache snapshot size sums files present in the pinned model snapshot.

CoNLL method

The dataset supplies tokens rather than original whitespace, so NERdact joins each example with spaces and scores exact character spans. This compares checkpoints consistently inside NERdact; it does not reproduce standard token-level CoNLL/seqeval scores.

What this comparison can establish

BERT base has a 512-token context and therefore uses overlapping 64-token windows here. ModernBERT supports 8192 tokens and receives each synthetic call in one pass. The ModernBERT checkpoint was only fine-tuned with sequences up to 256 tokens, however, so architectural capacity does not establish learned long-context NER quality. The checkpoints also differ in scale, tokenizer, publisher, and fine-tuning procedure; this is not a controlled architecture test.

Quality versus cost conclusion

Chunked BERT recovered 100.0% of exact long-fixture entities with 0.0% character leakage; ModernBERT recovered 33.3% with 32.4% leakage. BERT also ran at 21.7 examples/s versus ModernBERT's 10.3/s. Here, overlap avoids BERT truncation and is both more accurate and cheaper. This does not show that separated windows preserve all document context, nor does it generalize beyond three deliberately simple fixtures.

Candidate gate and contamination limits

The accepted ModernBERT checkpoint documents the nine BIO labels, CoNLL-2003 sample counts, train/validation/test results, max fine-tuning length, hyperparameters, and Apache-2.0 license. Its dataset revision and source code are not pinned, so this project pins the model snapshot and independently evaluates the CoNLL validation subset. This is a practical checkpoint result, not an independently reproducible architecture experiment.
