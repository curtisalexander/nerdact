What this comparison can—and cannot—say

The larger RoBERTa checkpoint reports stronger validation performance and was separately tested by its author on informal email/chat text. It also has roughly three times as many parameters, so quality comes with higher download, memory, and inference costs.

A perfect score on ten designed examples is encouraging, not proof of safety. This corpus is intentionally small and synthetic. The next meaningful step is a larger, independently labeled transcript set with harder negatives and entity types that match the intended redaction policy.

Data leakage avoided

The RoBERTa model card says its author included the original CoNLL test split in training. Reporting that split would produce a contaminated comparison, so this run uses the held-out validation split instead. Dataset access remains subject to the Reuters terms described in the project README.

uv run --extra benchmark nerdact compare --limit 200
