Two comparisons, different conclusions

The three dslim checkpoints form the cleaner size experiment: one publisher, one four-label CoNLL task, and DistilBERT/BERT encoders at roughly 66M, 110M, and 340M parameters. Even this does not prove that scale alone caused every difference because each checkpoint is a separately fine-tuned artifact.

RoBERTa-large is a practical checkpoint comparison, not a controlled architecture experiment. It changes model family, tokenizer, scale, and fine-tuning procedure at once. A perfect score on ten designed examples is encouraging, not proof of safety; a larger, independently labeled transcript set remains necessary.

Data leakage avoided

The RoBERTa model card says its author included the original CoNLL test split in training. Reporting that split would produce a contaminated comparison, so this run uses the held-out validation split instead. Dataset access remains subject to the Reuters terms described in the project README.
